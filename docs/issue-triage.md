# Issue Triage Guide

Good issue activity should reduce maintainer uncertainty.

## Useful Issue Comment

- Confirms whether the problem reproduces
- Names the environment, version, or input involved
- Links to the relevant file, docs page, or failing behavior
- Suggests the smallest next step

## Avoid

- Generic "I can work on this" comments without a plan
- Duplicate reports without linking the existing issue
- Asking for assignment before understanding the bug
- Opening issues only to create contribution activity
