# Contribution Quality Rubric

Use this rubric before posting a commit, issue, pull request, or review.

## Ready

A ready contribution has:

- A clear title, summary, and impact statement
- Verification evidence, such as tests or manual reproduction steps
- Enough context for a maintainer to understand the change
- Known risks or tradeoffs called out honestly

## Needs Polish

A contribution needs polish when the idea is useful but missing one of the
signals above. Improve the description or add verification before publishing.

## Not Ready

A contribution is not ready when it mostly exists to create activity. Rewrite it
around a real bug, docs gap, reproducible review finding, or useful maintenance
task.
