# Changelog

## 0.2.0

- Added structured contribution plan validation and strict CLI mode.
- Added JSON schema, CSV, and HTML export support.
- Added score filtering and summary aggregations.
- Added recommendation text in Markdown and HTML reports.
- Added more docs for validation, exports, examples, and safe public data.

## 0.1.0

- Added a contribution quality scoring model.
- Added JSON plan loading and Markdown report generation.
- Added a CLI for scoring planned GitHub contributions.
- Added tests for models, scoring, loading, and reporting.
- Added docs for review, issue triage, pull request planning, and terminology.
